> Generated by dev-impl / 2026-05-22 / status: done

## 採用方針 (Plan A/B のハイブリッド)

タスク雛形は Plan A (env 注入) または Plan B (`.env.test`) の選択肢を提示していたが、
どちらの単独でも 001/002 で `vite.config.ts` に **無条件で** 追加した `basicSsl()`
を打ち消せない。E2E/smoke はページを `http://localhost:5173|5174` で navigate
しているため、Vite が常時 HTTPS を返す状態だと page load 自体が壊れる。

そこで **mode-aware な vite.config.ts** と **.env.test** を組み合わせた:

| ファイル | 役割 |
|---|---|
| `vite.config.ts` (両アプリ) | `mode === "test"` のとき basicSsl/https/proxy をスキップ、それ以外 (= `pnpm dev`) は 001/002 の挙動を維持 |
| `apps/{customer,staff}-app/.env.test` (新規) | `VITE_RPC_URL=https://127.0.0.1:8443/rpc` 等を `.env` から上書きし、kit を外部 :8443 proxy に戻す |
| `e2e/global-setup.ts`, `e2e/fixtures.ts`, `scripts/smoke-*.mjs` | Vite spawn 時に `--mode test` を付与 |

`scripts/sa-setup.mjs` は customer/staff Vite を起動せず sa-harness (:5180) のみを
駆動するため変更不要。

## 変更ファイル
