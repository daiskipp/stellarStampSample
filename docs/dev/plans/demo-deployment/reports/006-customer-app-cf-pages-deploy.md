### 🔵 前工程指示（レビュー低優先）

- `_redirects` / `_headers` のファイル名と位置 — CF Pages 公式コンベンション (`apps/<name>/public/`) に準拠、タスク Implementation Notes 通り

### 🟡 妥当な推測（要確認）

- **CSP を採用しなかった** — Phase 1 デモで CSP 誤設定が WebAuthn / Google Fonts / soroban-testnet.stellar.org への CORS を silently に切ると検知が困難なため。Phase 2 で third-party origin set を確定してから追加する想定。`X-Frame-Options: DENY` で clickjacking のみ確実に塞ぐ
- **`wrangler.toml` を作らない** — CF Pages はダッシュボード設定が標準。Pages Functions を追加する Phase 1.5 (Task 008-012) で `apps/<app>/wrangler.toml` を検討
- **2-pass デプロイ手順** — `VITE_RP_ID` は実 host に合わせる必要があるが初回 deploy では確定しないため。kit/WebAuthn 一般のパターン
