## Requirements Summary

`just` をリポジトリに導入し、CLAUDE.md の **One-Shot Pipeline (localnet、順序必須)** を
`just localnet` という単一コマンドに集約する。既存の `scripts/*.sh|.mjs` は touch
せず、justfile から薄く wrap するだけ。`just --list` でレシピ一覧が出る形にして、
`just build` / `just deploy-localnet` のような **atomic** な再実行も可能にする。

CLAUDE.md と `docs/dev/context.md` の "Commands" 表は just コマンドを主、bash
コマンドを折りたたみで併記する形に更新する。

## Design Overview

### justfile 全体像（最終形）

```just
# justfile (project root)

set shell := ["bash", "-cu"]

# show the recipe list when invoked without args
default:
    @just --list --unsorted

# ── localnet atomic recipes ───────────────────────────────────────────────
# Each recipe wraps a single existing script with no transformation.

build:
    stellar contract build

test-contracts: build
    cargo test

deploy-localnet:
    bash scripts/deploy-localnet.sh

bindings:
    bash scripts/generate-bindings.sh

sa-harness:
    pnpm --filter sa-harness dev

sa-setup:
    node scripts/sa-setup.mjs

# ── composite: localnet One-shot pipeline ─────────────────────────────────
# build → deploy → bindings → spawn sa-harness in bg → wait for ready →
# sa-setup → kill harness. Mirrors CLAUDE.md's One-Shot Pipeline.

localnet: build deploy-localnet bindings
    #!/usr/bin/env bash
    set -euo pipefail
    HARNESS_LOG=$(mktemp -t sa-harness.XXXXXX.log)
    echo "[just localnet] starting sa-harness (log: $HARNESS_LOG)…"
    pnpm --filter sa-harness dev >"$HARNESS_LOG" 2>&1 &
    HARNESS_PID=$!
    trap 'kill "$HARNESS_PID" 2>/dev/null || true; rm -f "$HARNESS_LOG"' EXIT
    for _ in $(seq 1 40); do
        grep -q "Local:" "$HARNESS_LOG" && break
        sleep 1
    done
    sleep 2
    echo "[just localnet] running sa-setup…"
    node scripts/sa-setup.mjs
    echo "[just localnet] done."
```

### 重要インターフェース

#### devcontainer Dockerfile (Task 001)

```dockerfile
# .devcontainer/Dockerfile, Node.js install の後
ARG JUST_VERSION=1.36.0
RUN curl --proto '=https' --tlsv1.2 -sSfL \
      https://just.systems/install.sh \
      | bash -s -- --tag "${JUST_VERSION}" --to /usr/local/bin
```

#### flake.nix (Task 001)

```nix
packages = with pkgs; [
  rustup pkg-config openssl cmake binaryen
  nodejs_22 pnpm
  just              # 🔵 NEW
  jq curl docker-client git
] ++ optionalStellarCli;
```

#### mise.toml (Task 001)

削除する。pnpm は Dockerfile (corepack) + nix flake で既に提供されている。

#### justfile (Task 002 + 003)

- recipe 名は CLAUDE.md の Commands 表とほぼ 1:1 対応  🔵
- 依存関係: `test-contracts` は `build` に、`localnet` は `build → deploy-localnet → bindings` に依存  🔵
- `localnet` の harness bg + wait + setup シーケンスは `e2e/global-setup.ts:104-157` の pattern を bash に置き換え  🟡
- `default` を `@just --list` にして「コマンド忘れ」を防ぐ  🟡
- shell は `["bash", "-cu"]` 固定（依存解決時の予期しない変数展開を避ける）  🟡

### 検証ポイント

| 項目 | 検証方法 | 出典 |
|------|----------|------|
| devcontainer rebuild 後に just が PATH に入る | `just --version` が `JUST_VERSION` 固定値を返す | Dockerfile に curl install 焼き付け |
| host で `nix develop` した時も just が入る | `nix develop -c just --version` | flake.nix の `pkgs.just` |
| mise 廃止後も pnpm が動く | `pnpm --version`（corepack 経由） | Dockerfile `corepack enable` |
| 既存 One-Shot Pipeline と等価 | `just localnet` 実行 → `node scripts/sa-setup.mjs` の出力と同一の HQ SA / 1 stamp 状態 | CLAUDE.md Commands |
| harness bg spawn / ready 検知 | `e2e/global-setup.ts:49 waitForStdout` の "Local:" needle と同じ | e2e/global-setup.ts |
| atomic 再実行可能 | `just build` / `just deploy-localnet` 等が独立して動く | 各 scripts/*.sh の冪等性に依存 |

  └─▶ [002 justfile-atomic-recipes]
        └─▶ [003 justfile-composite-localnet]
